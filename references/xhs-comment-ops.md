# 小红书评论检查与回复

使用 [Codex 浏览器流程](codex-browser.md) 操作用户选定的浏览器。评论检查本身不授权发送回复。

## 检查

从通知页或目标笔记评论区读取实际可见评论。记录目标账号、笔记、评论者、评论正文和时间；页面未显示的数据写“未获取”。遇到辱骂、钓鱼、隐私或平台提示时标明风险。

## 单条回复

1. 在目标评论所在行打开回复入口，核对用户名与评论文本片段。
2. 生成与当前账号语气一致的可编辑回复。不能虚构经历、优惠、后续承诺或客服处理结果。
3. 用户已明确要求发送该回复时，填写后再次核对对象和正文；若仅要求拟稿，停在草稿。
4. 点击发送一次。以可见回复或成功状态确认；结果不明标记“待核实”，不重复发送。
5. 多条评论逐条对应、逐条核对；遇到操作频繁、网络异常、登录失效或页面对象漂移时暂停。

页面输入控件可能是普通文本框或富文本。按当前浏览器工具支持的方法输入，不沿用其他浏览器工具的 `type`/`fill` 参数假设。不要通过固定等待间隔规避平台限制。
