# 参考笔记到原创内容

目标是学习参考笔记的结构和信息表达，生成适合当前账号的新内容；不复制原文、原图或独特视觉元素。

1. 用 Codex 浏览器或用户指定的 Chrome 打开链接，核对标题、作者、正文、当前可见封面及图片顺序。无法访问时说明未获取哪些字段。
2. 记录来源 URL 与采集时间，拆解标题钩子、封面信息层级、正文节奏、互动问题及实际显示的指标。推荐原因或“爆款机制”属于推断，要写明依据与样本范围。
3. 结合当前账号定位，提出不同于原文的切入角度和事实需求。尚未核实的事实列为待补，不编入成稿。
4. 提供原创标题、正文、话题和封面/配图方案。若用户需要图片，优先使用其自有素材或另行创作；参考图只供研究，未经明确授权不加入待发布稿。
5. 用户要求继续发布时，接 [发布流程](xhs-publish-flows.md)。

若轮播页面包含隐藏或重复图片，以当前可见页和页面顺序为准，不用固定 CSS 选择器推断封面。若参考内容与新稿过于相似，重新设计句式、例子、信息层级和视觉元素。
